# Skyrim — Grimoire Nordique

Application mobile web pour GitHub Pages.

## Mise en ligne
1. Créer un dépôt GitHub.
2. Envoyer **tout le contenu de ce dossier** à la racine du dépôt.
3. GitHub → Settings → Pages.
4. Choisir `Deploy from a branch`, puis `main` et `/ (root)`.
5. Ouvrir l'adresse GitHub Pages sur le téléphone.

## Important
Cette version utilise une gestion d'inventaire entièrement locale avec `localStorage`.
Les boutons **+** et **−** fonctionnent par index d'ingrédient et ne dépendent pas du nom de l'ingrédient.
La progression est sauvegardée sur l'appareil.
