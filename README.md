# Skyrim Grimoire Nordique — V3

Version mobile autonome.

**Important : cette version ne charge plus les données avec `fetch()` et n'utilise plus de dossier `data/`. Les 110 ingrédients et 35 recettes sont intégrés directement dans `index.html`. Cela évite l'erreur « Données introuvables » sur GitHub Pages.

Mettre uniquement `index.html` dans le dépôt suffit. GitHub Pages peut ensuite servir directement le fichier.
